# Güvenlik

Gezegen Atölyesi tamamen tarayıcıda çalışır; sunucu, hesap ya da kişisel veri tutmaz. Kayıtlar yalnızca kullanıcının kendi tarayıcısında (localStorage) saklanır.

Yine de bir güvenlik açığı bulduğunu düşünüyorsan lütfen herkese açık bir issue açmak yerine GitHub'ın [özel güvenlik bildirimi](https://github.com/MesutYilmazJS/gezegen-atolyesi/security/advisories/new) özelliğini kullan.

Repoya asla şifre, API anahtarı ya da token eklemeyin. Sürüm 3'te gelecek bulut kayıt özelliği için gereken anahtarlar yalnızca ortam değişkenlerinde (`.env`, git'e eklenmez) tutulacaktır.
